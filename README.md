# 📊 Sales Performance & Business Intelligence Analysis

## 🎯 Business Problem & Objective
The goal of this project is to analyze company sales data to track Key Performance Indicators (KPIs), understand customer purchasing behavior, and identify top-performing products. This analysis helps the business optimize sales strategies and maximize revenue.

## 🛠️ Tech Stack & Tools Used
- **Database & Data Cleaning:** SQL (SQL Server)
- **Data Visualization & BI:** Power BI
- **Documentation:** Excel & GitHub

## 🔑 Key Insights & Deliverables
- **Interactive Dashboard:** Built a comprehensive Power BI dashboard featuring dynamic sales overview and product performance tabs.
- **Data Transformation:** Cleaned and structured raw transactional data using advanced SQL queries for accurate reporting.
- **Actionable Insights:** Identified key regional sales trends and top contributing product categories to support data-driven decision-making.
